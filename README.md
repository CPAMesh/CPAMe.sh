# Central PA Mesh — Astro Site (CPAMe.sh)

Attractive, simple, SEO-optimized informational site for the Central PA Mesh community.

## Features
- Uses your logo and blue/green mesh colors
- Strong local SEO (keywords, structured data, Open Graph, geo meta)
- Optimized for searches like “Meshcore Pennsylvania”, “LoRa mesh Harrisburg”, “Meshtastic Central PA”, etc.
- Easy to maintain (Astro components + plain content)
- Ready for Cloudflare Pages

## Local development
```bash
# Requires Node 22+
npm install
npm run dev
```

## Deploy to Cloudflare Pages
1. Push this folder to a GitHub repository.
2. In Cloudflare Dashboard → Workers & Pages → Create application → Pages → Connect to Git.
3. Build command: `npm run build`
4. Build output directory: `dist`
5. Add custom domain: `cpame.sh`
